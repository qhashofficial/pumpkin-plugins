# @pumpkin-plugins/plugin-kit

[![npm downloads](https://img.shields.io/npm/dt/%40pumpkin-plugins%2Fplugin-kit)](https://www.npmjs.com/package/@pumpkin-plugins/plugin-kit)
[![latest npm release](https://img.shields.io/npm/v/%40pumpkin-plugins%2Fplugin-kit?label=latest%20release)](https://www.npmjs.com/package/@pumpkin-plugins/plugin-kit)
[![npm license](https://img.shields.io/npm/l/%40pumpkin-plugins%2Fplugin-kit)](https://www.npmjs.com/package/@pumpkin-plugins/plugin-kit)

Shared building blocks for Pumpkin plugins: a plugin base class and registration wrapper, data
folders, logging, scheduled tasks, command registration, plugin messages and binary payload
encoders, plus in-memory fakes for tests. `PluginBase` builds Pumpkin metadata from your
`PluginInfo`, and `registerPlugin` starts the non-blocking Pumpkin Market update check after the
plugin loads.

The [plugin-kit guide](docs/index.md) covers the lifecycle, scheduling, data folders, commands and
test fakes. [Plugin info and READMEs](../../docs/plugin-info-and-readmes.md) explains `PluginInfo`
and command declarations, and the [code style guide](../../docs/code-style.md) covers shared
conventions such as log colors.
