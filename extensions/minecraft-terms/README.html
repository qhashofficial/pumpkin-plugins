Minecraft Terms ​

This extension adds Minecraft terminology to Code Spell Checker. The same dictionary is available to the cspell command-line linter through @pumpkin-plugins/cspell-dict-minecraft. It covers Minecraft terms and names, not PumpkinMC-specific terminology.

See the API reference on the documentation site.

To use the dictionary in VS Code, install Code Spell Checker and this extension. When VS Code starts, the extension registers its packaged dictionary with Code Spell Checker. In an npm project, install @pumpkin-plugins/cspell-dict-minecraft and import its cspell-ext.json in your CSpell configuration. The dictionary package's install instructions include the pnpm command and a YAML example.

The GitHub release includes a VSIX for this extension. To install it, download the .vsix file, then in VS Code select Extensions: Install from VSIX... and choose that file.
